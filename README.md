# Matin & Gulfisha Wedding Invitation

A digital wedding invitation for the Dawat-e-Walima event, built as a static HTML/CSS/JavaScript site.

## Project structure

- `index.html` — invitation page structure
- `styles.css` — custom styling, typography, spacing, and responsive behavior
- `script.js` — scene switching and UI interactions
- `assets/` — local design/reference assets (currently ignored from git)

## Local preview

Open the project in a browser or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Notes

- This version is meant to preserve the printed invitation aesthetic while improving the digital experience.
- The cover and Walima sections are designed with a warm paper-card look, floral borders, Urdu/English presentation, and mobile-friendly spacing.
- The `assets/` folder is currently ignored in Git so it is not pushed until you are ready to publish those files.

## Deployment

This project is intended to be published through GitHub Pages once the repository is pushed to GitHub.
